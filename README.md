# Лабораторная работа №3

## Описание

Вариант 4 — Калькулятор комплексных чисел (`Complex`)

Лабораторная работа посвящена перегрузке операций в C++

Стандарт языка: C++14

Документация к коду создаётся с помощью Doxygen

UML-диаграмма создаётся с помощью PlantUML

## Часть 5

Реализован класс `Complex`: три конструктора, методы чтения, вывод информации, статический счетчик существующих объектов и деструктор

Добавлены префиксные и постфиксные `++` и `--`. Они изменяют действительную часть на 1, мнимая часть сохраняется

Добавлены арифметические присваивания `+=`, `-=`, `*=`, `/=`. Деление на ноль и переполнение отклоняются без изменения числа

Бинарные `+`, `-`, `*`, `/` используют соответствующие арифметические присваивания и возвращают новое число. Исходные операнды сохраняются

Добавлены все шесть сравнений. `<`, `>`, `<=`, `>=` сравнивают модули, а `==` и `!=` — обе части числа

Калькулятор позволяет ввести текущее число, выполнить любую из реализованных операций и просмотреть историю. Неправильный ввод можно повторить, ошибки арифметики не меняют текущее число

Автоматические проверки запускаются через `--test`. Они используют все конструкторы и перегрузки, проверяют калькулятор, историю и счетчик объектов

## Сборка программы

Для сборки используется файл `build.bat`. Нужен компилятор `g++` в PATH

```powershell
.\build.bat
.\build\lab3.exe
```

Для запуска автоматических проверок:

```powershell
.\build\lab3.exe --test
```

## Создание документации

```powershell
.\docs.bat
```

Открыть файл `docs/html/index.html`

Файл `docs.bat` запускает Doxygen и копирует диаграмму в документацию. Нужен установленный Doxygen

Исходник диаграммы можно открыть в редакторе с PlantUML или перерисовать с помощью Java:

```powershell
java -jar plantuml.jar -tsvg uml/complex.puml
```
