Вариант 4 — Калькулятор комплексных чисел

**Обязательные требования**

| Требование | Выполнение |
| --- | --- |
| Класс Complex | Первый этап |
| Три конструктора | Без аргументов, параметризованный, копирование |
| Префиксные и постфиксные ++ и -- | Реализованы и проверены в части 2 |
| +=, -=, *=, /= | Реализованы и проверены в части 3 |
| +, -, *, / через арифметическое присваивание | Реализованы и проверены в части 4 |
| <, >, <=, >=, ==, != | Реализованы и проверены в части 4 |
| Статическое поле | Счетчик существующих объектов |
| Собственный деструктор | Уменьшает счетчик объектов |
| Использование всех конструкторов и перегрузок | Проверки и калькулятор в готовой работе |
| Просмотр истории операций | Пятый этап |
| Подробное документирование Doxygen | Комментарии к классу и функциям, страницы документации |
| UML через PlantUML | Исходник и готовая диаграмма |
| Не менее пяти осмысленных коммитов | Отдельный коммит каждого этапа по команде пользователя |
| Понимание кода | Описание полей, действий и проверок |

**План работы**

1. Проектирование, класс, конструкторы, счетчик и деструктор
2. Унарные операции
3. Арифметические присваивания
4. Бинарная арифметика и сравнения
5. Калькулятор, история, полные проверки и документация

В конце работы проверить все перегрузки, возвращаемые значения префиксных и постфиксных операций, неизменность исходных операндов бинарной арифметики и реакцию на деление на ноль

На сайте список арифметических присваиваний повреждён форматированием. В работе он понимается как `+=`, `-=`, `*=`, `/=`
