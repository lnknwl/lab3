# Унарные операции

**Описание**

В классе Complex реализованы четыре перегрузки:

- `++number` — увеличивает действительную часть на 1 и возвращает ссылку на измененное число
- `number++` — увеличивает действительную часть на 1, но возвращает копию старого числа
- `--number` — уменьшает действительную часть на 1 и возвращает ссылку на измененное число
- `number--` — уменьшает действительную часть на 1, но возвращает копию старого числа

Мнимая часть во всех случаях сохраняется

**Разница между формами**

Если `number` равно `3 + 4i`, после `Complex old = number++` число равно `4 + 4i`, а `old` равно `3 + 4i`

Если использовать `Complex& result = ++number`, то `result` ссылается на то же число и содержит уже измененные данные

Параметр int у постфиксной формы нужен для отличия перегрузок. Его значение в программе не используется

Постфикс сначала сохраняет копию, затем вызывает префиксную операцию и возвращает сохраненное число. Поэтому логика изменения не повторяется

**Проверка результата**

Метод `changeRealPart()` сначала вычисляет новую действительную часть и проверяет её и модуль. Только после этого изменяет поле

У double ограничена точность. Для очень большого числа прибавление 1 может дать то же самое число. Такой случай отклоняется через `std::overflow_error`, чтобы операция не сообщала об изменении, которого не произошло

При ошибке поля исходного числа и счетчик сохраняются. Если в постфиксной операции успела создаться копия, при исключении её деструктор автоматически уменьшает счетчик

**Проверки**

В main проверяются старые и новые значения, возврат ссылки, независимость копии, отрицательные числа, переход через ноль, последовательные префиксные операции и время жизни временных результатов
