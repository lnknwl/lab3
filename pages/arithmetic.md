# Арифметические присваивания

**Описание**

Операции `+=`, `-=`, `*=`, `/=` изменяют левое число и возвращают ссылку на него. Правое число принимается по константной ссылке

Для чисел `a + bi` и `c + di` используются формулы:

```text
Сложение: (a + c) + (b + d)i
Вычитание: (a - c) + (b - d)i
Умножение: (ac - bd) + (ad + bc)i
Деление: (ac + bd) / (c² + d²) + ((bc - ad) / (c² + d²))i
```

Если обе части делителя нулевые, выбрасывается `std::domain_error`. Деление на ноль не выполняется

**Сохранение состояния**

В умножении и делении исходные части сначала сохраняются в локальных переменных. Поэтому операции `number *= number` и `number /= number` используют старые значения обеих частей

Метод `assignResult()` проверяет новые части и модуль, затем сохраняет оба поля. Если результат не помещается в double, выбрасывается `std::overflow_error`, исходное число сохраняется

Промежуточные вычисления выполняются в long double. У используемого g++ из MSYS2 этот тип имеет больший диапазон, чем double. Это позволяет делить большие и очень маленькие числа без переполнения или обнуления промежуточных квадратов

В полях результат по-прежнему хранится в double и округляется до точности этого типа. На компиляторе, где диапазон long double совпадает с double, обработка крайних значений может отличаться

**Результат примера**

Для исходного числа `3 + 4i` и правого операнда `1 - 2i`:

```text
После +=: 4 + 2i
После -=: 3 + 4i
После *=: 11 - 2i
После /=: 3 + 4i
```

**Проверки**

Проверены результаты и возвращаемые ссылки, неизменность правого операнда, операции с самим собой, нулевые числа, переполнение частей и модуля, деление больших и маленьких чисел. При ошибках проверяется сохранение обоих операндов и счетчика объектов
