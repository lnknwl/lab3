# Проектирование класса

**Описание**

Комплексное число состоит из действительной и мнимой частей. Например, у числа `3 + 4i` действительная часть равна 3, а мнимая равна 4

В классе части числа хранятся в двух закрытых полях типа double. Для чтения используются const-методы

**Таблица класса**

| Элемент | Описание |
| --- | --- |
| Имя класса | `Complex` — комплексное число |
| Поля | `realPart` и `imaginaryPart`, тип double, секция private |
| Статическое поле | `objectCount` — количество существующих объектов |
| Конструкторы | Без аргументов, с двумя частями числа, копирование |
| Методы чтения | `getRealPart()`, `getImaginaryPart()`, `getModulus()` |
| Вывод информации | `printInfo() const` |
| Счетчик | `getObjectCount()` |
| Деструктор | Уменьшает счетчик на один |

**Условия корректности**

- Обе части числа должны быть конечными: NaN и бесконечность недопустимы
- Модуль должен помещаться в double и быть конечным
- Число без аргументов равно `0 + 0i`
- Копия хранит собственные значения и считается отдельным объектом
- Неудачное создание объекта не изменяет счетчик

Модуль числа вычисляется через `std::hypot(realPart, imaginaryPart)`. Для числа `3 + 4i` он равен 5. Эта функция помогает избежать переполнения промежуточных квадратов

**Следующие этапы**

- Префиксные и постфиксные `++` и `--` изменяют действительную часть на 1
- `+=`, `-=`, `*=`, `/=` изменяют левый операнд
- `+`, `-`, `*`, `/` используют арифметическое присваивание и возвращают новое число
- `<`, `>`, `<=`, `>=` сравнивают модули
- `==` и `!=` сравнивают действительную и мнимую части. Числа с равными модулями могут быть разными
- Деление на `0 + 0i` отклоняется
- При неправильной операции или переполнении исходное число сохраняется
- Калькулятор хранит историю операций и позволяет её просмотреть

**Работа счетчика**

Статическое поле одно для всего класса. Каждый успешно выполненный конструктор увеличивает его, а деструктор уменьшает

Конструктор копирования создаёт ещё один объект, поэтому тоже увеличивает счетчик. Присваивание копирует данные в уже существующий объект и не меняет счетчик

В программе используется стандартный оператор присваивания `= default`. Требуемые заданием перегрузки будут добавляться отдельно
