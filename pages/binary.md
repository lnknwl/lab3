# Бинарные операции и сравнения

**Арифметика**

Операции `+`, `-`, `*`, `/` объявлены как const-методы. Они возвращают новое число и не изменяют исходные операнды

Для сложения сначала создаётся копия левого числа, затем к ней применяется `+=` с правым числом. Остальные операции устроены так же и используют `-=`, `*=`, `/=`. Это выполняет обязательное требование задания и не дублирует формулы

```cpp
Complex result(*this);
result += other;
return result;
```

Проверки результата и деления на ноль остаются в арифметических присваиваниях. Если они выбросили исключение, локальная копия уничтожается и счетчик уменьшается

**Сравнения**

- `<`, `>`, `<=`, `>=` сравнивают модули, вычисленные через `getModulus()`
- `==` сравнивает действительные и мнимые части
- `!=` возвращает результат, противоположный `==`

У чисел `3 + 4i` и `-3 + 4i` одинаковый модуль 5, но сами числа разные. Поэтому для них оба условия `<=` и `>=` истинны, а `==` ложно

Сравнение модулей — выбранное правило калькулятора, а не обычный математический порядок комплексных чисел

Поля double сравниваются точно, без допуска. Результат вычислений может округляться, поэтому в тестах арифметики используется отдельная функция `hasParts()` с погрешностью. Пользовательские операторы равенства от этой функции не зависят

**Проверки**

Проверены результаты всех четырех арифметических операций, неизменность операндов, независимость возвращенного числа, составные выражения, операции с нулем и самим собой

При делении на ноль и переполнении проверяется нужный тип ошибки, исходные части обоих чисел и счетчик

Все шесть сравнений проверены для разных чисел, равных чисел и одного объекта. Отдельно проверены одинаковые модули у разных чисел, отрицательная действительная часть и границы диапазона
