# Работа калькулятора

**Меню**

После запуска текущее число равно `0 + 0i`

- `1` — ввести действительную и мнимую части через пробел
- `2` — выбрать операцию
- `3` — посмотреть историю
- `0` — завершить программу

Дробная часть вводится через точку, например `1.5 -2.5`. В строке должны быть ровно два конечных числа. Если введены лишние данные или неправильное число, программа предлагает повторить ввод

В пункте 2 доступны `+`, `-`, `*`, `/`, `+=`, `-=`, `*=`, `/=`, `++a`, `a++`, `--a`, `a--`, `<`, `>`, `<=`, `>=`, `==`, `!=`. Для бинарной операции после выбора вводится второе число

Результат арифметики становится текущим числом. Сравнения выводят true или false и сохраняют текущее число. Для постфиксных операций отдельно показываются возвращенное старое значение и новое текущее число

**История**

История содержит успешные операции в порядке выполнения: исходные числа, обозначение операции и результат. Ввод нового числа не стирает прежние записи

Ошибочные операции в историю не добавляются. После деления на ноль или переполнения текущее число сохраняется. История хранится в памяти до завершения программы

**Организация кода**

`Complex` выполняет арифметику. Класс `Calculator` хранит текущее число и вектор строк истории. Функция `runCalculator()` отвечает за меню и ввод

В `calculate()` сначала вычисляется результат на отдельной копии. После успешного выполнения формируется запись истории и сохраняется новое число. Это позволяет оставить старое состояние при ошибке

`formatNumber()` записывает число в строку. Используется точность `max_digits10`, чтобы при просмотре истории не терялись значащие цифры double

**Проверки**

Команда `lab3.exe --test` запускает проверки всех перегрузок и трех конструкторов. Для калькулятора проверяются все операции, порядок истории, сохранение состояния при ошибках и независимость переданных чисел

Для меню используются строковые потоки: программа получает заранее подготовленный ввод и сравнивает фактический вывод с ожидаемыми результатами. Отдельно проверяются повторный ввод и завершение потока
